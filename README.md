# erp-hangool

Planning files for the Hangool Construction ERP.

## Files

- `hangool-erd.html`: entity relationship diagram of the database. It shows all 39 tables, colour-coded by section (Access, Sales, Projects, Design, BOQ, Approvals, Procurement, Inventory, Site, Finance, HR, Client portal, Marketing), with primary keys, foreign keys, relationship lines and a notes panel listing the design assumptions.

## How to view the diagram

Download `hangool-erd.html` and open it in any web browser. You don't need to install anything, but you do need internet, because the page loads Mermaid from a CDN to draw the diagram.

- Scroll or pinch to zoom, and drag to pan.
- Use the **Section** menu, or click a colour in the legend, to show one section and the tables linked to it.
